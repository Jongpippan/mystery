# 06. Images as evidence and scene direction

## Visual facts

Establish art direction after the new concept, not from inherited assets. Record the size, count, shape, damage, placement, clothing, and possessions that matter to reasoning. An inconsistent observation feature is a case-logic error, even if labeled a diagram. Do not draw decorative doors that do not exist or reveal unopened contents.

Evidence detail is image-centered: show the features the player must observe in the document, photograph, object view, or diagram. Include legible dimensions, text, marks, damage, and arrangement. Preserve original Korean text and accessible transcription where needed. Brief context and incidental life detail are welcome when consistent with truth. Explain unfamiliar purposes through scenes and demonstrations; do not replace every missing visual fact with a long explanatory paragraph.

## Thumbnails and detail

Every E has a unique thumbnail and a detailed image or accurate document rendering. Small versions preserve recognizable silhouette, composition, object, or document type. Within similar document types, use real fold/arrangement/stamp differences. Numbered or recolored generic duplicates are inadequate.

If two items must look identical for the case, distinguish neutral presentation without exaggerating a forgery clue. Names, alt text, filenames, tooltips, crop previews, and filters must not reveal future conclusions or unknown identities. Thumbnails and detail must agree.

## Scene states

| State | Image purpose |
|---|---|
| First visit | Space, visible objects, context, atmosphere |
| Conversation | Recognizable speaker/expression and who is interacting |
| Major event | The action or material change happening now |
| Discovery | Connection between location and observed object state |
| Revisit | Updated lighting, objects, and people matching world state |
| Reconstruction | Distinguish hypotheses, confirmed facts, and recollection |
| Aftermath | Return to the location's actual post-event state |

Do not use a static background with portraits as the only treatment of every major event. Supply meaningful scene compositions or state transformations with reactions before and after. A reconstruction image must not certify a hypothesis as true before proof.

## Asset record and creation

For each A record purpose, activation conditions, related E/V/P/L, source and derivative paths, production method, required visible features, prohibited disclosures, alt text, crop/zoom, and review evidence.

Use suitable image tools for photos, illustrations, portraits, and situation cuts. Exact Korean document text, numerical tables, plans, and diagrams may use text/vector/code rendering for accuracy. Do not entrust crucial writing and numbers solely to generated pixels. Select reusable assets only if they fit the independently designed work.

Compose around dialogue and tool overlays. Ensure small-screen cropping does not hide required observations; support zoom for detailed inspection. Sufficiently large dialogue portraits and readable action directions are governed by [05](05-ui-and-investigation.md).

## Visual verification

Inspect all thumbnails together at actual list size. Compare important shapes, dimensions, outfits, exits, and object positions across scenes. Capture major event before/during/after states. Check initial play for spoilers in images and metadata, acquisition popup behavior, fast advance, save restoration, large text, and small-screen cropping.

File existence and matching IDs support but do not replace viewing actual rendered images. This documentation cleanup requires no image production and claims no art verification for a future game.
