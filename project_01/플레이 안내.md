# 여울관: 남겨 둔 자리

[게임 시작.cmd](게임%20시작.cmd)를 더블클릭하면 브라우저에서 게임이 열립니다. 이미 실행 중이면 [게임 열기](http://127.0.0.1:4173/)로 들어갈 수 있습니다.

프롤로그와 6개 조사 장, 에필로그로 구성된 한국어 추리 게임입니다. 이름을 정한 뒤 시작하세요. 대사와 지문을 읽고, 자료를 확인하고, 자신의 주장과 근거를 선택해 사건을 풀어갑니다.

- **조사 도구**: 증거·인물·지도·대화·메모는 추리 중에도 열 수 있습니다. 도구를 닫으면 읽던 위치와 답안으로 돌아갑니다.
- **이동**: 현장이나 지도에 표시된 방향을 선택합니다. 잠시 다른 곳에 갔다면 연결된 길을 따라 조사하던 자리로 돌아오세요.
- **여유**: 시작·최대 6. 완성된 틀린 주장 제출은 2 감소합니다. 자료 열람·편집·불완전 답안·힌트는 무료입니다. 0이 되면 ‘잠깐 정리하고 이어가기’로 4를 회복하며, 횟수 제한은 없습니다.
- **힌트**: 조사할 곳부터 해답과 이유까지 다섯 단계입니다. 요청한 단계만 표시됩니다.
- **글자·음향**: 설정에서 글자를 최대 200%로 확대하고 음량·음소거를 바꿀 수 있습니다. 소리는 재생을 선택할 때만 나오며 자막으로도 비교할 수 있습니다.
- **저장**: 같은 PC·브라우저의 게임 주소에 자동 저장됩니다. 설정에서 직접 저장하거나 다른 슬롯을 불러올 수 있습니다. 엔딩 뒤 새 슬롯을 시작해도 이전 플레이는 보존됩니다.

클릭·터치 또는 키보드 Tab/Enter로 조작합니다. Esc는 현재 조사 도구를 닫습니다. 엔딩 뒤에는 사건 보관함에서 실제로 들은 대화, 진술의 변화, 제출한 추리와 선택을 다시 볼 수 있습니다.

실행에 문제가 있으면 `game/.vinext/game-error.log`와 `game/.vinext/game-start.log`에 기록이 남습니다. 현재 작업 폴더에는 빌드와 의존성이 준비되어 있습니다. 개발 환경에서 다시 준비할 때는 `game` 폴더에서 `npm.cmd run install:ci`, `npm.cmd run build`를 실행합니다.

제작자의 기능·화면 검사는 완료 보고서에 기록되어 있습니다. 독립적인 첫 플레이테스트는 아직 실시하지 않았습니다.
