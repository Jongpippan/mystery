# 장과 사건 상태

사건 시각과 플레이 회차는 분리한다. 도착20:00 이후 조사 회차만 흐르며 현실의 초 단위 제한은 없다. 세계 변화는 선행 명제를 확정할 때 준비되고, 발견은 해당 장소 명시적 방문 때 일어난다. 열람 탭의 지도는 이동이 아니다.

## 이벤트 계약

공통: 한 번 실행 ID로 기록한다. `pending→active(step)→done`, 중간 저장 시 같은 대사 위치로 재개. 효과는 확인 후 한 번만 원자 반영한다. 진행 중 다른 이벤트는 우선순위 순 큐에 둔다. 장소를 떠나 놓치면 pending 유지. 닫기·사진 열람·대화 건너뛰기로 증거나 기록이 소실되지 않는다. 종료 후 현 장소의 새 상태 이미지로 복귀한다. 장면 A_V번호는 해당 변화 전용 구도를 사용한다.

|---|---|---|---|
