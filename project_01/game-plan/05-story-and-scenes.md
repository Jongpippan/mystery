## Global scene contract

All C have Korean title/action/dialogue, source-defined cast/location/time, entry and exit, player-known E/S/K, forbidden future disclosure, repeat behavior and saved line. Each spoken S is unique. Shared task response/hint scenes have real individual wording, not a single repeated template. Author context below is English; actual script will be direct Korean.

Scene ID categories:

- `C_PR_01..16`: prologue scenes below.
- `C_CHnn_01..08`: chapter's eight core conversational/event scenes; specific purposes below.
- `C_CHnn_O1..O3`: three separately assigned relationship/ordinary scenes per chapter; skippable without lost proof.
- `C_D01..30`, `C_Q01..06`: **36 full challenge scenes**, each with context/clarification, every accepted-equivalent claim's spoken realization, specific wrong-premise responses, success and retained-draft retry. Exact logical conditions in `03-deduction.md`, target S in `08-challenges-and-hints.md`.
- `C_H_D01..30`, `C_H_Q01..06`: **36 requested hint scenes**, each with actual H0–H4, missing-evidence/held-evidence variants and failure-sensitive text. Not ordinary unsolicited companion dialogue.
- `C_H_V01..06`: required revisit/acquisition bottleneck hints; actual H0–H4, no future clue titles before discovery.
- `C_SYS_01..04`: zero/recovery, rest, tool/safety clarification, display-name introduction/validation. These are full Korean scenes, not silent system toasts.
- `C_EP_01..06`: closure/ending scenes below.

The resulting coverage is determined by this design; its count is not proof of breadth or a target to reduce to. Additional scenes are added if a transition or alternative needs one. No optional banter contains unique mandatory evidence. Distinct branches merge only if knowledge and relationships permit it; source-dependent wording remains conditional.

## Internal writing units and source ownership

The user requested fewer file relays. [The consolidated workflow](12-writing-workflow.md) now governs handoff: all remaining scenes are one full writing assignment, completed in bounded internal units in the same writing conversation and returned as one full draft ZIP. Every external assignment includes the actual accepted text relevant to continuity and the whole author truth. IDs for each scene's new S lines use `S_<C suffix>_0001..0999`; persistent testimony S_Qnn_v1/v2 is reserved exclusively to its initial/corrected utterance, referenced elsewhere instead of duplicated as a new current statement. Revisions retain existing IDs and report additions/retirements. Actual accepted source and review provenance are indexed in `scripts/README.md`.
