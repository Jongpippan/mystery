# 잔향 조사실 01 — 마지막 인쇄

2026-09-10 / project_01 / 기획 v1 / 새 시리즈 첫 작품. 선행 작품·사건·인물 없음.

사용자 승인 범위는 새로운 게임의 기획, 구현, 검증, 시리즈 인계다. 기존 프로젝트와 재사용 에셋은 참고하지 않았다. 공통 00~09, 초기화된 series 3문서와 사건 서식을 읽었다.

## 작품 약속

2008년 가상 항구도시 해온. 폐관을 앞둔 물결 인쇄관은 옛 침수 피해 주민들이 교정한 증언을 마지막으로 인쇄하려 한다. 인쇄 직전 구리 원판이 사라지고, 전시 책임자는 재인쇄용 복제판으로 행사를 계속하려 한다. 플레이어는 누가 원판을 옮겼는지뿐 아니라 어떤 시각과 경로가 가능한지, 왜 단순 도난으로 설명할 수 없는지를 입증한다. 폭력·사망 묘사는 없다. 피해는 타인의 말을 지우는 행위다.

시리즈 주제는 ‘남겨진 기록과 기록 밖의 사람’. 주인공 유서안(P01, CHAR_001)은 주민기록조합의 분쟁 조사원이다. 인쇄관과 조합의 보존협약으로 현장·운영 기록을 열람하고, 당사자 동의 아래 질문한다. 체포·수색 영장을 발부하는 권한은 없다. 직원이 보존 상자를 개봉하고 조사 결과는 공동 운영위원회에 전달한다. 기술과 권한은 이 가상 세계에서만 설정한 규칙이다.

조수 차모은(P02, CHAR_002)은 기록 접근성 담당자로, 구술·도면을 읽기 쉬운 형태로 옮긴다. 오늘이 두 사람의 첫 공동 현장이다. 서안은 물건을 반듯하게 놓고 질문도 그렇게 정리하려 한다. 모은은 사람의 말이 반듯하지 않을 권리를 기억시킨다. 조수는 범행 전 현장에 없었고, 20:00 서안과 도착한다. 독자적으로 시계 비교 실험과 보관함 보존 요청을 수행한다. 고의 가담·은폐·과거 공모 없음.

## 규모와 경험

서막 + 본편 4장 + 종막. 주인공·조수와 NPC 5명, 7장소, 자료 E01~E24, Q01~Q04, D01~D08, 최종 F01~F05. 주요 이벤트 V01~V10. 각 장은 독립 조사 두 흐름, 추론 2개, 추궁 1개, 원인이 있는 상태 변화를 포함한다. 120~180분은 첫 플레이 **목표 가설**이며 미실측이다. 난이도나 길이를 줄여 완료 처리하지 않는다. 첫 플레이가 짧으면 글자 수를 늘리지 않고 경쟁 가설·판정의 사고 단계를 검토한다.

세 경쟁 가설: 정비사의 서비스 통로 반출, 제본사의 카트 반출, 전시 책임자의 정상 출입구 운반. 물리적 접근 가능성, 시간 기준, 실제 운반량, 고의와 대안 배제를 각각 입증한다. 가장 짧은 완주도 4추궁·8추론·5최종 주장과 재방문 검증을 거친다. 범인 이름만 맞혀서는 끝나지 않는다.

## 실행 설계

외부 계정·유료 서비스가 없는 로컬 웹 게임. 정적 HTML/CSS/JavaScript와 JSON 데이터, Node 기반 로컬 서버·테스트. 키보드·마우스·터치, 1440×900 및 390×844를 우선 검증한다. 저장은 버전이 있는 단일 localStorage 스냅샷, 수동 JSON 내보내기·가져오기. 제작 문서는 스포일러이며 플레이에 필요하지 않다.

미술은 먹색·종이색·청록 강조의 인쇄관 기록물. 정확한 증거·도면은 개별 벡터 도해, 공간·인물의 표정과 상황은 전용 이미지로 제작한다. 미술 수단 때문에 세계를 변경하지 않는다.

R01~R17은 08-state-and-validation.md에서 요구별 설계/구현/검증 상태를 추적한다. 자동 완주와 제작자 시각 검수는 독립 첫 플레이의 재미·난이도 검증을 대신하지 않는다.
