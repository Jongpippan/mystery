# 판정·포인트·힌트 계약

논증 신뢰도100 시작, 최대100. 제출 전 오답 비용 표시: D/Q -10, 최종 F -15. 읽기·이동·질문·자세히 묻기·힌트·전략·성격 선택은0. 빈칸/선택 수 누락은 무료 차단. 한 제출의 복수 오류는 한번 차감. 같은 제출 토큰의 재처리는 무효. 피드백을 읽고 다시 누르는 제출은 새로운 시도다. 성공 보상은 ID마다 한번+10, 장 진입은 최초 한번 최소60.

0점은 사건 정리 상태로 전환. 자료·로그·메모·이미 입증한 명제·관계·열람 위치 유지, 유료 제출 금지. ‘정리 후 재도전’으로60 회복, 현재 실패 답안만 비우고 같은 과제 유지. 회복횟수 무제한. 정답·증거 무료 지급 없음. 낮은 점수나 힌트로 나쁜 결말을 만들지 않는다.

Q01~04의 대상·발언·정정·근거는 02/04 문서의 원문을 사용한다. 제출은 대상 진술, 두 개 이상 확보 자료, 모순의 이유. 오답 피드백은 진술 오류/자료 부족/설명 오류를 구분하고 틀린 전제를 설명한다. 정정 버전은 v1 원문과 v2 정정·계기 Q를 함께 보존한다. E09/E11/E19/E23은 해당 Q 성공에만 처음 얻는다.

## 힌트 원문

힌트는 현재 D/Q/F ID별로 H0~H4를 개별 저장하고 사용자가 ‘다음 단계’를 눌러야 높인다. 필요한 자료가 없을 때 H0와 H4 위에는 현재 접근 가능한 획득 장소·행동을 안내한다. 미래 자료 제목을 탐색 안내에 먼저 노출하지 않는다. 해당 과제 잠금 자체가 미해결이면 그 선행 과제를 안내한다. H4도 미래 과제의 답을 말하지 않는다.

최종 F01~05 H0는 해당 질문에 필요한 확보 자료가 모두 읽을 수 있음을 안내, H1은 행위/시각/연결/고의/대안 중 입증 범위, H2는02 문서의 해당 묶음, H3는 각각 운반→회수/실물→봉인/대여→실사용/삭제승인→은닉/물리경로→남는정상문을 설명한다. H4는02 문서의 정확한 선택과 자료를 제시한다. 최종 답을 한꺼번에 보이지 않고 현재 주장만 설명한다.

재방문 H0: V03 접수실에 사진 회신 확인, V04 회랑 비교대, V05 기계실 안전 차단 확인, V06 종이실 영상 동의, V07 인쇄실 교정쇄 비교, V08 낭독실 보존 요청 결과, V09 낭독실 입회 개봉. 필수 변화는 영구 대기한다.

상태는 단일 reducer에서 검증→변경→저장 스냅샷→화면 갱신. 제출 ID·보상 ID·실패수·힌트 단계·버전·과제·임시 답안까지 같이 저장한다. 힌트/자료 열람으로 제출 함수가 호출되지 않으며, Esc는 열람만 닫는다.
