# 물결 인쇄관 공간 검산

단층 건물의 개념도. 그림 길이는 축척이 아니다. 모든 사람이 이용하는 문은 폭90cm, 케이스68×50cm 운반 가능. 도면과 게임은 동일한 L/R 좌표·연결 데이터를 쓴다. 서비스 구멍은 사람이 이동하는 통로가 아니다. 폐관 전 직원5명이 출입 권한을 공유하므로 독점 열쇠로 책임을 확정하지 않는다.

```text
       [L04 기계실]             [L03 종이실]
             | R04 1분              | R03 1분
[L06 반출구]—R06 2분—[L05 서회랑]—R01 1분—[L01 접수실]
                         | R02 1분              | R07 1분
                    [L02 인쇄실]—R05 1분—[L07 낭독실]
```

위 도식은 연결 설명용. 구현 도면은 L05-L02 서쪽 문, L02-L07 동쪽 문과 낭독실 뒤 받침대 출입을 구분한다. 인쇄실→서회랑→접수실→낭독실은3분. 인쇄실→낭독실 직접은1분이지만19:06~16 공개 부스 촬영 동선으로 막혀 있어 큰 짐 통과는 촬영에 남는다. 나경은 서회랑 저울을 거쳐 접수실 뒤 공개 복도를 사용한다. 인터뷰 촬영은 부스 내부와 동쪽 문만 보며 받침대 뒤 출입은 보지 못한다.

| R | 연결·조건·시간 | 시야·물체·근거 |
|---|---|---|
| R01 | L05↔L01, 양방향1분 | 차광막이 인쇄실 서쪽 문 시야 차단, 큰 케이스 통과 가능 / E06,E13 |
| R02 | L05↔L02, 서쪽 문1분 | 별도 잠금 없음, 빛 반사가 판 목격 아님 / E09 |
| R03 | L01↔L03,1분 | 접수실 유리창에서 작업대 양손·얼굴 확인 / E16 |
| R04 | L05↔L04,1분 | 기계실 출입은 가능하나 축 안쪽 실측은 안전 차단 후 / E14 |
| R05 | L02↔L07,1분 | 부스 촬영에 동쪽 문 전체가 보임, 서쪽 받침대 출입은 별도 / E20 |
| R06 | L05↔L06,2분 | 직원 문90cm, 외부카메라는 반출구 전체·실내는 못 봄 / E17 |
| R07 | L01↔L07,1분 | 공개 복도→낭독실 뒤, 큰 짐 가능, 부스 카메라 밖 / E13,E20 |

L02-L04 서비스 구멍은 지름32cm, 길이1.5m, 축 배선 전용. 원판 최소 단면44cm이므로 통과 불가. 평면도에는 점선 비이동 연결로 표시. 전원·축 정지는 접근 안전 조건이며 구멍을 넓히는 조건이 아니다.

범행: 19:08 인쇄대 분리·케이스 포장1분→R02 1분→19:10~11 저울 작업1분→R01 1분→R07 1분→19:13~14 아래칸 은닉1분→19:15 부스 합류. 분 단위 증거의 오차는 약1분이므로 답안에 요구하는 범위는19:06~16이다. 사진은19:11 특정 순간의 하중 연결에만 사용한다.

대안: 서비스 구멍 반출은 시간과 무관하게 물체 제약 위반. 정비사가 정상 문 사용은19:04~18 연속 점검 영상·내선으로 배제. 제본사 수레 반출은3.0kg<11.2kg(빈수레2+원판9.2), 손 운반은19:06~16 연속 위치로 배제. 배송원 대리 운반은19:03~18 외부 인계 기록, 문서는19:06 실물 확인→이동→17까지 부스 연속 자료로 배제. ‘모든 직원이 공모했다’는 근거 없는 추가 가정은 인정 가설이 아니며, 객관 기록을 모두 무효라고 두는 주장도 게임 내 근거가 없다.

재방문: L01 사진 회신(E12), L05 확대 원본(E13), L04 축 안전 차단 실측(E14), L03 공개 동의 영상(E16), L02 문서가 가져온 교정쇄(E22), L07 전시물 제거→흔적(E21)→직원 입회 개봉(E24). 처음 없거나 읽을 수 없는 이유와 원인은 이벤트 문서에 기록했다.

지도 현재 위치는 실제 move 행동만 변경한다. 인물 위치는 ‘마지막 확인: 장·회차’로 표시, 개인 상세에 출처 로그 링크. 과거 사건 위치는 확보 E로 확인된 시점만 추가한다. 잠금은 이유 표시. 조사 중 장소를 옮기는 시간은 논증 사건 시각과 무관하다.
