# UI와 자산 계획

먹색 바탕, 따뜻한 종이빛 본문, 청록 상태 강조, 주황 경고. 장 제목·장면·조사 선택이 주 작업 영역에 있고 좌측 고정 내비게이션에 현장/자료/인물/지도/대화/메모/설정. 답안은 별도 유지 영역에 두며 열람은 그 옆 패널을 바꾼다. 작은 화면은 공통 탭을 상단에, 답안과 열람을 세로로 둔다. 닫기·Esc로 답안으로 돌아가되 선택·검색·스크롤·초점·HP를 보존한다.

자료 행72px 시작, 고유 이미지56px, 본문16px, 버튼44px 이상. 데스크톱 자료8행/인물6행이 목록 높이에 보이는지 캡처 검수.200% 글자 확대에서는 밀도보다 가독성. 미획득 자료는 총수/제목/썸네일 미노출. 획득순/사건순, 종류·장소·인물 필터, 검색 조합. 상세는 원문·출처·획득시각·사건시각·관련 인물 링크·고유 도해, 근거 선택 버튼은 상세보기와 분리한다.

인물 상세: 알려진 소개/원문 진술·버전·계기/확인된 타임라인과 본인 주장 구별/관련 확보 자료/관찰한 관계/마지막 확인 장소·회차. 작가 진상과 미래 자료를 가져오지 않는다. 대화 목록은 종류→묶음→실제 발언, 종류·인물·키워드 필터. 뒤로 가면 목록 검색/스크롤 복구.

답안: D는 결론과 근거 조합, Q는 대상 진술·근거·논리, F는 주장별 결론·인물·근거. 선택 수·해제 표시. 선택 제한을 조용히 덮어쓰지 않으며 빈 제출은 비용 없이 설명한다. 장면 이벤트는 확인 버튼으로 진행하고 자동 타이머 없음. 동료 상담과 과거 로그 열람은 사건을 진행시키지 않는다.

## 자산 원장

각 A_E01~24는 `assets/evidence/E번호.svg`의 상세와 축소 이미지로 동일 핵심 특징 유지. 사건 수치는 SVG 텍스트와 HTML 원문에 정확히 중복 제공한다. 개별 형상은 다음과 같다.

E01 세 칸 인쇄순서 접지, E02 구리 모서리 세 타각과 탁본, E03 원형구멍·찢긴천, E04 방송 스피커와 띠, E05 잠금종이띠·봉인, E06 차광막 바퀴와 금박, E07 다섯 고리의 열쇠판, E08 두 둥근 시계가 든 사진, E09 시야 부채꼴과 반사면, E10 붉은천·젖은 종이, E11 네 바퀴 수레·계량표, E12 한 프레임 두 시계·삼각대, E13 손잡이 큰 케이스·저울, E14 원형실측틀과 직사각판 비교, E15 축·캠코더, E16 매단 제본지·창틀, E17 화물상자·인수펜, E18 U쇠와 대여카드, E19 하중 그래프 띠, E20 릴/파형·부스, E21 아래칸·U자 압흔, E22 두 판본 나란히 교정선, E23 비대칭 파임 도구와 맞춤자국, E24 구리판 세 타각·입회 봉인. 같은 문서 아이콘에 숫자만 바꾸지 않는다.

인물 A_P01~07: 04 문서 외형으로 새 초상. 배경 A_L01~07: 평면도 구조에 맞추고 쓸모없는 문을 추가하지 않는다. A_V00~10: 중단표지/빈인쇄대갈등/반사실험/동시촬영/사진확대/안전실측/영상동의/두판본대질/받침대노출/입회개봉/결과발표를 장면별 전용 구도로 표현한다. 초상만 배경 위에 바꾸는 연출로 대체하지 않는다. 주요 물체의 치수는 생성 이미지에 맡기지 않고 정확 도해로 보여 준다.

래스터 삽화 제작에는 imagegen 스킬·내장 도구를 사용한다. 제작 프롬프트·결과 경로는 `assets/manifest.json`에 기록하고 최종 파일은 이 프로젝트 안에 둔다. 정밀 도면·문서는 코드/벡터로 작성한다. 생성 실패 시 사용 가능한 구현은 계속하되 실패·누락은 미완료로 남긴다.

모든 자산 대체텍스트는 보이는 대상만 설명한다. ‘범인’ ‘가짜’ 등 아직 입증하지 않은 결론을 파일명/alt에 쓰지 않는다. 확인된 사실·가설·회상을 명시. 상황 이미지 종료 후 이벤트 완료 ID에 맞는 장소 변형으로 복귀. 실제 렌더링된 전체 썸네일 모음과 사건 전·중·후 화면을 검수하고 경로 존재 검사로 대신하지 않는다.
