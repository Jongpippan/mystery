# SYS — 기록을 이어가는 방법

- Packet: `YEOWUL-FULL-v1`
- Revision: `r01`
- Status: `draft`
- Coverage: C_SYS_01..04
- Rules: 여유 start/max 6; committed wrong logical claim -2; incomplete/free inspection/questions/hints/relationship choices cost 0; zero recovery restores 4 without losing state.

## C_SYS_01 — 잠깐 정리하고 이어가기

### Context
- Trigger: an unresolved D/Q reaches `여유 0`
- Entry state: current task, editable failed draft, most recent useful error feedback, E/K/S/B/notes/history all retained
- Exit: `여유 4 / 6`, same unresolved task and same editable draft
- World effects: no new E/K/B, no time advance, repeatable without limit

### Script — first zero, safe public/family context

*제출 결과의 붉은 밑줄은 남아 있지만 입력창이 잠긴다. 화면 오른쪽의 자료·노트·대화 기록은 그대로 열 수 있다.*

> **여유 0 / 6**  
> 지금 주장은 더 밀어붙이지 않는 편이 좋습니다.  
> 마지막 답안과 피드백은 지워지지 않습니다.
>
> - `잠깐 정리하고 이어가기`
> - `자료를 더 읽기` — 무료
> - `힌트 보기` — 무료, 요청한 단계만

**P00 | 나여백 [S_SYS_01_0001]**

내가 지금 같은 전제를 세 번 고집했네. 답을 처음부터 없애지 말고, 틀린 부분만 고치자.

#### If P01 is safely present in L02/public context

**P01 | 나모눈 [S_SYS_01_0011]**

맞아. 우리가 모은 자료도, 방금 받은 반박도 그대로 둘게. 잠깐 정리하고 같은 질문으로 돌아가자.

**P07 | 진새벽 [S_SYS_01_0021]**

여기서 멈춰도 조사 기록은 없어지지 않습니다. 방금 제출한 주장과 반박을 그대로 두고, 근거를 다시 보죠.

*플레이어가 `잠깐 정리하고 이어가기`를 선택한다.*

> **정리 완료 — 여유 4 / 6**  
> 보존됨: 획득 자료, 입증한 결론, 진술 버전, 관계 선택, 노트, 대화 기록, 현재 답안 초안, 직전 오류 피드백.

*같은 D/Q 답안 화면으로 복귀한다. 직전 커서/선택 가능한 범위까지 유지한다.*

> 회복 횟수는 결말이나 관계에 영향을 주지 않습니다.

**P00 | 나여백 [S_SYS_01_0051]**

읽는 건 제출이 아니니까 여유를 쓰지 않습니다. 자료를 확인한 뒤 이 답안으로 돌아오겠습니다.

*자료/인물/대화/지도 도구를 자유롭게 열고 닫은 뒤 동일한 0점 답안 화면으로 돌아온다. 회복 버튼은 계속 남는다.*

### Save/resume at zero

**P00 | 나여백 [S_SYS_01_0091]**
