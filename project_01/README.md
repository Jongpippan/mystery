# 잔향 조사실 01 — 마지막 인쇄

가상 도시 해온의 물결 인쇄관에서 주민 증언의 구리 원판이 사라졌습니다. 기록 조사원 유서안과 동료 차모은이 되어, 목격의 범위·시계·운반 경로·사람의 말을 교차 검증하세요.

현재 제작 및 검증 중입니다. 서막·본편 4장·종막의 진행과 시스템 검증은 수행했고, 일부 시각 자산과 문서 대조를 마무리하고 있습니다. 재미·난이도·120~180분 목표는 독립 첫 플레이로 아직 검증하지 않았습니다.

## 실행

Node.js가 설치된 Windows에서 `play.cmd`를 실행하거나 이 폴더에서 다음 명령을 사용합니다.

```powershell
npm.cmd start
```

브라우저에서 <http://127.0.0.1:4173>을 여세요. 종료할 때 서버 창에서 Ctrl+C를 누릅니다. 게임 실행에는 계정·인터넷·npm 패키지 설치가 필요 없습니다. `index.html`을 파일로 직접 여는 방식은 지원하지 않습니다.

## 조사 방법

- 현장에서 자료를 살펴보고 일반 질문으로 발언 범위를 확인합니다. 지도에는 실제 통로와 소요 시간이 있습니다.
- 오른쪽 논증 작업대에서 결론·대상 진술·근거를 선택합니다. 시간 과제에서는 사건 카드를 위아래 버튼으로 배치합니다.
- 답안을 작성하며 자료·인물·지도·대화·메모 탭을 모두 열 수 있습니다. 탭 열람은 이동이나 제출이 아닙니다.
- 잘못된 주장은10점, 최종 주장은15점이 줄어듭니다. 0점에서 자료와 메모를 보존하고60점으로 회복합니다. 피드백을 확인한 뒤 다시 제출하세요.
- 모은에게 요청하는 힌트는 H0~H4입니다. 마지막 단계는 현재 과제의 명시적 해법이며 사용 불이익은 없습니다.
- 새 사건 확인은 해당 장소에서 기다립니다. 오른쪽 다음 행동 안내와 힌트로 재방문 경로를 찾을 수 있습니다.

같은 브라우저에 자동 저장됩니다. 설정에서 JSON 저장을 내보내거나 가져올 수 있습니다. 파일 가져오기와 새 게임은 기존 기록을 별도 백업합니다. 개인 정보나 플레이 기록을 외부로 전송하지 않습니다.

## 제작자 검증

```powershell
npm.cmd run build
npm.cmd test
npm.cmd ci
node scripts/browser-check.mjs
```

빌드는 기획 원문에서 공개 자료·대사와 정확 도해를 생성합니다. 브라우저 검증은 설치된 Windows Chrome과 개발 의존성 Playwright를 사용하며 자체 테스트 서버(4175)를 열고 닫습니다. 일반 게임 실행에는 Playwright가 필요 없습니다.

`game-plan/`과 `validation/`에는 정답·결말이 있습니다. 검증 범위와 남은 일은 `game-plan/08-state-and-validation.md`, 시리즈 인계는 `game-plan/09-series-handoff-SPOILERS.md`에 기록합니다.
